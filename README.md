# 🏷️ HelpDesk

An enterprise-oriented help desk and ticket management system built with .NET Core and Angular

## 🎖️ Badges

.NET Core | Angular | SQL Server | EF Core | Docker | xUnit

## 📖 Overview

HelpDesk is an enterprise-oriented ticket management system designed to manage support requests throughout their lifecycle, from creation and assignment to resolution and history tracking.

### 💜 Backend

.NET Core Web API responsible for:

- Business rules
- Authentication and authorization
- Ticket management
- User and role management
- Domain events
- Persistence
- API endpoints

### ❤️ Frontend

Angular application responsible for:

- User interface
- Authentication experience
- Ticket management UI
- Administration
- Localization
- Client-side interaction with the API

## ✨ Features

### Authentication & Authorization

- JWT-based authentication
- Access and refresh tokens

- Fine-grained permissions

### Ticket Management

- Create and manage tickets
- Ticket assignment

- Current and assigned ticket views
